# Video requests only

Use this reference only when the requested deliverable includes video. Keep UI work and image-only tasks out of this production workflow.

Prefer a code-first composition with intentional typography, timing, transitions, product material and motion. Do not fill scenes with cliché AI pictures. Cloud rendering is the default; discover the available authorized renderer and its current capabilities. Do not use RunPod without authorization in the current task. If cloud rendering is unavailable, report that before choosing another route; do not silently spend elsewhere.

An explicit budget wins. Otherwise the maximum is **US$5 total for the whole video**, including generation, voice, music and render, with room for any approved retry. Unknown or incomparable prices do not mean zero cost; resolve them before production. A provider credit count alone is not a dollar total. Do not split work into jobs to evade the cap.

Before producing, present the concrete plan, providers, duration/format and total estimate and ask for approval immediately before submission, unless the current explicit user request already authorizes that production scope and spend. Existing authorization persists for that same concrete action. Planning, choosing media and writing a prompt are not authorization to produce. New providers/subscriptions require approval even when the overall amount is small.

Use the media routing reference for any requested Higgsfield/Replicate generation. Discover current models and input schemas; do not use stale model IDs. Record job IDs and investigate an uncertain result before retrying. Prefer small, approved iterations and reuse successful assets within the budget.

Review the rendered output itself: watch it with audio, check pacing, typography, transitions, framing, codec/dimensions, duration, audio synchronization and whether it satisfies the complete brief. Inspect representative frames but do not call frame inspection a full playback review. Deliver the final artifact, source composition when requested, full final prompt when relevant, actual/estimated cost distinction and any unverified item.
